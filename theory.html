Theoretical Background

Dichromatic Number

Definition

The dichromatic number \(\chi_d(G)\) of a directed graph \(G = (V, E)\) is defined as:

\[\chi_d(G) = \min\{k : V \text{ can be partitioned into } k \text{ acyclic subgraphs}\}\]

In other words, it is the minimum number of colors needed to color the vertices of \(G\) such that each color class induces a directed acyclic subgraph (DAG).

Properties

  1. Bounds: For a directed graph \(G\) on \(n\) vertices:

    \[1 \leq \chi_d(G) \leq n\]

    • \(\chi_d(G) = 1\) if and only if \(G\) is acyclic (is a DAG)

    • \(\chi_d(G) = n\) only for very specific graph structures

  2. Relationship to Chromatic Number: For undirected graphs, the chromatic number and dichromatic number have different meanings:

    • Undirected chromatic number counts proper vertex colorings

    • Dichromatic number requires acyclicity in color classes

  3. Cycle Relation: Every directed cycle requires at least 2 colors:

    • A 3-cycle \(0 \to 1 \to 2 \to 0\) has \(\chi_d = 2\)

    • A \(k\)-cycle with \(k \geq 3\) has \(\chi_d = 2\)

  4. Digons: 2-cycles (digons) between vertices can be treated specially:

    • With allow_digons=True: Digons are colored with 1 color

    • With allow_digons=False: Digons require 2 colors

Algorithms

This package uses backtracking to compute acyclic colorings:

  1. Order vertices of \(G\)

  2. For each vertex, determine which colors are safe

  3. A color is safe if assigning it doesn’t create a monochromatic directed cycle

  4. Use DFS to check for cycles within each color class

  5. Backtrack if no safe color exists for a vertex

Time Complexity

  • Enumerating all acyclic \(k\)-colorings: Exponential in worst case

  • Computing dichromatic number: \(O(n \cdot T(k))\) where \(T(k)\) is time to check all \(k\)-colorings

Dihomomorphisms

Definition

A dihomomorphism from directed graph \(D\) to directed graph \(E\) is a vertex map \(f: V(D) \to V(E)\) satisfying:

  1. Arc Condition: For every arc \(u \to v\) in \(D\):

    \[f(u) \to f(v) \in E \quad \text{or} \quad f(u) = f(v)\]

  2. Acyclicity Condition: For every vertex \(w \in V(E)\), the induced subgraph:

    \[D[f^{-1}(w)] \text{ is acyclic}\]

Key Properties

  1. Self-loops Forbidden: If \(D\) has a self-loop, no dihomomorphism exists (the preimage would be cyclic)

  2. DAGs Map to DAGs: If \(D\) is acyclic, then \(D\) can always map to any target graph \(E\) with vertices

  3. Existence Conditions: - If \(D\) is empty, exactly one dihomomorphism exists (empty map) - If \(E\) is empty and \(D\) non-empty, no dihomomorphism exists - Cycles in \(D\) severely restrict possible mappings

  4. Complete Mapping Space: All dihomomorphisms from \(D\) to \(E\) form a discrete set

Examples

Single Arc to Single Arc:

Source: \(D = 0 \to 1\), Target: \(E = 0 \to 1\)

Dihomomorphisms:

  • \(f_1: \{0 \mapsto 0, 1 \mapsto 0\}\) (both vertices map to 0)

  • \(f_2: \{0 \mapsto 0, 1 \mapsto 1\}\) (preserving arc)

  • \(f_3: \{0 \mapsto 1, 1 \mapsto 1\}\) (both vertices map to 1)

All three satisfy:

  • Arc condition: Each preserves the arc structure

  • Acyclicity: Each preimage (single vertex or two vertices with arc) is acyclic

3-Cycle Cannot Map to Point:

Source: \(D = 0 \to 1 \to 2 \to 0\), Target: \(E = \{w\}\) (single vertex)

If all vertices map to \(w\), the preimage \(f^{-1}(w) = \{0, 1, 2\}\) contains the 3-cycle, violating acyclicity.

DAG Can Collapse:

Source: \(D = 0 \to 1 \to 2\) (path, acyclic), Target: \(E = \{w\}\)

The map \(f: \{0 \mapsto w, 1 \mapsto w, 2 \mapsto w\}\) works because \(f^{-1}(w) = D\) is acyclic.

Dihomomorphism Graph

Given digraphs \(D\) and \(E\), the dihomomorphism graph \(G\) is defined as:

  • Vertices: All dihomomorphisms from \(D\) to \(E\)

  • Edges: Two dihomomorphisms \(f, h\) are adjacent if for every arc \(x \to y\) in \(D\):

    \[f(x) \to h(y) \in E \quad \text{and} \quad h(x) \to f(y) \in E\]

This adjacency condition captures the structure of “compatible” dihomomorphisms and enables topological analysis of the mapping space.

Applications

The dihomomorphism graph is used to study: - Homotopy type of mapping spaces - Clique complexes of dihomomorphism graphs - Topological properties of directed graph structures
