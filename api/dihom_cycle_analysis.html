Dihom Cycle Analysis

For each non-isomorphic digraph G of order n, compute its dichromatic number and the homotopy type of the clique complex of the dihomomorphism graph Hom_di(D, G), where D is a chosen source digraph.

Usage

uv run python -m dicolor.dihom_cycle_analysis <order> [–domain {cycle,arc}]

[–cycle-order K] [–format {org,csv}]

where order is an integer between 1 and 6. The source domain D is selected with --domain:

  • cycle (default) — directed cycle C_k; use --cycle-order K to set k (defaults to order).

  • arc — the single directed arc: two vertices, one directed edge.

Results are written to dihom_cycle_analysis_<order>_c<k>.org (cycle) or dihom_arc_analysis_<order>.org (arc) by default.

The digraphs are indexed starting from 0, matching the position in the digraph6 data files from Brendan McKay’s database. Digons (2-cycles) are always treated as directed cycles when computing the dichromatic number.

Columns

  • # — 0-based index of the digraph G.

  • Edges — number of arcs in G.

  • chi_d — dichromatic number of G (digons counted as cycles).

  • Homotopy type of CC(Hom(D, G)) — homotopy type of the clique complex of the undirected dihomomorphism graph from D to G. Reported as “empty” when no dihomomorphism exists.
